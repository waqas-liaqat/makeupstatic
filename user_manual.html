Remembered forever — zero effort next time

✓ Premakeup Moisturizer (remembered)

Automatic matching levels (tried in order):

Level 0
Saved memory — you confirmed this match before → instant match, no AI
Level 1
Exact catalog number — SKU on invoice matches Airtable SKU exactly (e.g. 100059)
Level 2
Partial SKU — barcode on invoice partially matches a known SKU
Level 3
Description keywords — key words from product name found in invoice line
Not found
No match → click 🔗 Link to confirm and teach the system

⚠️ 4. Negative Inventory Alerts New in v5.0

Previously the system stopped at 0 even if more units were sold than available. Now it shows the real number — including negatives — so gaps are visible.

What you'll see
  • A red ⚠️ Negative Stock banner on the Overview page
  • Stock values in red in the Products table for affected items
  • The exact deficit shown (e.g. ⚠ -3)
Why it matters
  • Flags a gap that needs investigation
  • Could be: missing delivery, unrecorded transfer, counting error
  • Previously gaps disappeared to 0 silently — now they're visible
Example: 2 units in stock, 5 sold → shows -3 instead of 0. Investigate: was there a missing delivery or an extra entry?

🛡️ 5. Data Rules & Notes

Customer matching:

Matched by Phone → Email → Name. If not found the transaction saves without a customer link. No fake records are created.

Sale vs Supplier invoices:

Sale invoices deduct stock. Supplier invoices add stock and create a Purchase Order record.

Real-time sync:

Every action saves directly to Airtable. No batch processing. The refresh button (bottom-left) reloads latest data.

Adding a new product:

Go to your Airtable base → Products table, add a new row with SKU, name, prices and minimum stock. Dashboard picks it up on next refresh.

Duplicate POS import:

If you import a file twice, use Manual Transaction → Manual Correction (positive quantity) to restore the extra-deducted stock.

6. Troubleshooting & FAQs

❌ Dashboard not loading / showing dashes
Wait 5–10 seconds. Click Refresh Data (bottom-left). Check internet connection.
❌ Invoice scan error or nothing extracted
Use a clearer, well-lit photo with the full invoice visible. Hard-refresh (Ctrl+Shift+R on desktop) and try again.
⚠️ Products showing "Not found" after scanning
Click 🔗 Link next to the row, select the correct product — it will be remembered for all future invoices automatically.
⚠️ Red "Negative Stock" banner on Overview
One or more products have more units sold than in stock. Go to Products, find the red values, and investigate — check for a missed delivery or duplicate sale entry.
❓ Can I scan a PDF invoice?
Yes — take a screenshot of the PDF and upload the image. Reads Hebrew and English text, printed and handwritten.
❓ Jerusalem branch receipts don't have catalog numbers yet
The system still tries to match by product name automatically. Once Jerusalem registers are updated to print catalog numbers, matching will become fully automatic there too.
❓ How do I fix a wrong transaction?
Use Manual Transaction → Manual Correction to add or remove the difference. For example if you accidentally deducted 5 instead of 3, add a correction of +2.
